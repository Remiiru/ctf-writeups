# CTF Writeups

Writeups de retos y máquinas de CTF que voy resolviendo — cómo identifiqué cada
vulnerabilidad, la explotación paso a paso, qué intenté que no funcionó y las
implicaciones prácticas para pentesting y bug bounty. La mayoría están en español y
están pensados para poder reproducirse: comandos reales, payloads y el razonamiento
detrás de cada decisión.

Autor: **Gerson Cornejo** ([@Remiiru](https://github.com/Remiiru)).
